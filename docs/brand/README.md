# Kontorfix — Brand

Freigegeben am 2026-07-08. Vollständiger Pitch mit Screendesigns: `kontorfix-brand.html`
(self-contained, Fonts eingebettet — im Browser öffnen).

## Bildmarke „Der Speichergiebel"

Treppengiebel eines hanseatischen Kontorhauses; das Tor ist der Registry-Zugang,
der Punkt darüber der Kranbalken. Dateien:

| Datei | Verwendung |
|-------|-----------|
| `logo-mark.svg` | Primär auf dunklem Grund (App, Readme dark) |
| `logo-mark-light.svg` | Auf hellem Grund |
| `favicon.svg` | Favicon/App-Icon (Kupfer-Fläche, funktioniert bis 14 px) |

## Wortmarke

`kontorfix` — Bricolage Grotesque 800, lowercase, letter-spacing −0.025em;
Suffix **fix** in Backstein-Kupfer `#D07A45`.

## Farbwelt „Hanse bei Nacht"

| Token | Hex | Rolle |
|-------|-----|-------|
| Seenacht | `#0D141F` | Grundfläche (dark-first) |
| Panel | `#151F2E` | Karten/Panels |
| Backstein-Kupfer | `#D07A45` | Akzent (einziger lauter Ton), Hover `#E29260` |
| Grünspan | `#7FB5A2` | Sekundär (npm-Badge, ruhige Hinweise) |
| Kontorpapier | `#E9E4D9` | Text auf dunkel |
| Semantik | `#6CBF8B` / `#D9A441` / `#D25B52` | ok / warn / crit — getrennt vom Akzent |

## Typografie

- **Display:** Bricolage Grotesque (800 Headlines, 500 Subline)
- **Body:** System-Stack
- **Data/Code:** JetBrains Mono — Paketnamen, Domains, Versionen, Tokens, Snippets
